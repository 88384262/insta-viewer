# InstaView - Visualizador de Perfis e Stories Públicos

Um projeto web moderno inspirado em serviços como StoryAnônimo e Insta Stories Viewer.

## 📁 Estrutura de Arquivos
- `public/index.html` - Interface web completa
- `public/style.css` - Estilização responsiva e tema escuro moderno
- `public/script.js` - Lógica do cliente (pesquisa, alternância de abas, renderização)
- `server.js` - Servidor Node.js / Express (pronto para rodar localmente e na Vercel)
- `vercel.json` - Configuração para deploy direto na Vercel

## 🚀 Como Executar Localmente
1. Certifique-se de ter o Node.js instalado.
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor:
   ```bash
   npm start
   ```
4. Acesse no navegador: `http://localhost:3000`

## ☁️ Deploy na Vercel
1. Suba este projeto para o seu repositório no GitHub.
2. Importe o projeto no painel da Vercel.
3. O deploy será realizado automaticamente sem necessidade de configurações adicionais.
